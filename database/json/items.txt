============================================================
MAPEO DE ESTRUCTURAS JSON PARA INSTANCIAS FÍSICAS (item_componente)
Sistema de Inventario - La Casa El Rapidito
============================================================

A continuación se detalla qué atributos debe contener el campo JSON 
(atributos_item_componente) según el tipo de componente físico que se 
esté registrando.

A diferencia de la tabla de catálogo (que guarda especificaciones 
teóricas del modelo), esta tabla guarda los valores REALES de la 
pieza física instalada, reportados por el Sistema Operativo o el 
Agente de inventario.


------------------------------------------------------------
1. PROCESADOR (item_procesador)
------------------------------------------------------------
Atributos: busid, frecuencia
{
  "busid": "0000:00:1f.1",
  "frecuencia": 3600
}


------------------------------------------------------------

===========================================================
NOTA DE IMPLEMENTACIÓN EN LARAVEL:
===========================================================
Al igual que en el catálogo, para saber qué validación aplicar al 
JSON entrante en la tabla unificada `item_componente`, el sistema 
debe obtener el nombre de la `categoria` heredada a través de la 
relación:

 $itemComponente->catalogoComponente->modelo->tipo->fabricante->categoria->nombre_categoria

Dependiendo de ese valor, el controlador aplicará las reglas de 
validación correspondientes para el JSON de la instancia física.
