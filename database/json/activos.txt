===========================================================
MAPEO DE ESTRUCTURAS JSON POR TIPO DE ACTIVO
Sistema de Inventario - La Casa El Rapidito
===========================================================

A continuación se detalla qué atributos debe contener el campo JSON 
(atributos_activo) según la categoría del activo 
definida en la relación jerárquica (categoria -> fabricante -> tipo -> modelo).


------------------------------------------------------------
1. COMPUTADORA (PCs, Laptops, Servidores físicos)
------------------------------------------------------------
Atributos: sistema_operativo, ultimo_inventory_update, ultimo_arranque
{
  "sistema_operativo": "Windows 11 Pro",
  "ultimo_inventory_update": "2026-05-02 03:58:29",
  "ultimo_arranque": "2026-05-01 19:14:38"
}


------------------------------------------------------------
2. PERIFÉRICO (Teclados, Ratones, Escáneres, Webcams)
------------------------------------------------------------
Atributos: marca_alt, modelo_alt, es_global
{
  "marca_alt": "Logitech",
  "modelo_alt": "B100",
  "es_global": 0
}


------------------------------------------------------------
3. MONITOR (Pantallas)
------------------------------------------------------------

{
  "tamano": 24.00,
  "tiene_micro": 0,
  "tiene_altavoz": 1,
  "tiene_subd": 1,
  "tiene_bnc": 0,
  "tiene_dvi": 1,
  "tiene_pivot": 1,
  "tiene_hdmi": 1,
  "tiene_displayport": 0,
  "es_global": 0
}


------------------------------------------------------------

------------------------------------------------------------

{
  "ram": 512,

------------------------------------------------------------

}

}


===========================================================
NOTA DE IMPLEMENTACIÓN EN LARAVEL:
===========================================================
Para saber cuál de estos JSON aplicar al momento de guardar o validar 
un registro en la tabla unificada `activo`, el sistema 
debe consultar el nombre de la `categoria` heredada a través de la 
relación del `id_modelo`:

 $activo->modelo->tipo->fabricante->categoria->nombre_categoria

Dependiendo de ese valor (ej. "COMPUTADORA", "MONITOR", "IMPRESORA"), el controlador 
aplicará las reglas de validación correspondientes para el JSON entrante en el 
campo `atributos_activo`.
