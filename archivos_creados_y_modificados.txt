1. SERVICIOS Y AUDITORÍA
-------------------------------------------------------------------------------
[CREADO] app/Services/BitacoraService.php
- Servicio encargado de registrar eventos de auditoría en la tabla `bitacora`.
- Captura automáticamente snapshot del usuario autenticado, IP, User Agent, URL y método HTTP.
- Sanitiza y excluye campos sensibles (contraseñas, tokens) antes de persistir los JSON de valores anteriores y nuevos.

2. MODELOS ELOQUENT
-------------------------------------------------------------------------------
[CREADO] app/Models/Bitacora.php
- Modelo de auditoría de solo lectura ($timestamps = false, primaryKey = id_bitacora).
- Relación con User y scopes para filtrado avanzado por usuario, acción, entidad, fechas e IP.

[CREADO] app/Models/Categoria.php
- Modelo de categorías de inventario ($timestamps = false, primaryKey = id_categoria).
- Relaciones padre/hijas/productos, scopes (active, inactive, search, byStatus) y método helper `generaJerarquiaCircular()`.

[CREADO] app/Models/Producto.php
- Modelo auxiliar para validación de categorías asociadas ($timestamps = false, primaryKey = id_producto).

[CREADO] app/Models/Rol.php
- Modelo de roles ($timestamps = false, primaryKey = id_rol).
- Relaciones pivote con Permiso y User, scopes (active, inactive, search, byStatus).

[CREADO] app/Models/Permiso.php
- Modelo de permisos ($timestamps = false, primaryKey = id_permiso).
- Relación pivote con Rol, scopes (active, inactive, search, byStatus, byModulo).

[CREADO] app/Models/RolUsuario.php
- Modelo de la tabla pivote `rol_usuario` ($timestamps = false, primaryKey = id_rol_usuario).

[CREADO] app/Models/PermisoRol.php
- Modelo de la tabla pivote `permiso_rol` ($timestamps = false, primaryKey = id_permiso_rol).

[MODIFICADO] app/Models/User.php
- Extensión del modelo User con campo status (1=activo, 2=inactivo), relación con roles y métodos RBAC (`hasRole`, `hasPermissionTo`).
